# زرین | Zarrin Jewelry

فروشگاه آنلاین طلا و جواهرات، ساخته‌شده با Next.js 16 (App Router) و Tailwind CSS v4، به‌صورت راست‌چین (RTL) و فارسی.

## اجرای پروژه

```bash
npm install
npm run dev
```

سپس آدرس `http://localhost:3000` را باز کنید.

## ساختار

- `app/layout.tsx` — چیدمان اصلی، فونت Vazirmatn و تنظیم `dir="rtl"`
- `app/page.tsx` — صفحه اصلی که بخش‌ها را کنار هم می‌چیند
- `components/` — Header، Hero (اسلایدر)، دسته‌بندی محصولات، محصولات پرفروش، بنر کالکشن جدید + چرا زرین، Footer
- `app/globals.css` — توکن‌های رنگ و فونت با `@theme` در Tailwind v4

## نکات

- تصاویر محصولات به‌صورت پلیس‌هولدر (کاشی طلایی + آیکون خطی جواهر) پیاده‌سازی شده تا بدون نیاز به عکس واقعی هم پروژه کامل و قابل اجرا باشد. کافی‌ست کامپوننت `JewelTile` را با `next/image` و عکس واقعی محصولات جایگزین کنید.
- شمارنده سبد خرید با Context ساده (`components/CartContext.tsx`) پیاده شده و برای اتصال به بک‌اند یا localStorage قابل گسترش است.
- رنگ‌ها و فونت در `app/globals.css` با دایرکتیو `@theme` تعریف شده‌اند (روش Tailwind v4)؛ برای تغییر پالت رنگی همان‌جا را ویرایش کنید.
