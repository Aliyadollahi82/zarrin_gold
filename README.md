# 💎 Zarin Gold

A modern and elegant e-commerce website for **Zarin Gold**, designed for showcasing and selling gold jewelry and accessories through a clean and premium online shopping experience.

## 🌐 Live Demo

[View Website](https://zarringold.vercel.app/)

## 🛠️ Technologies

* Next.js 16
* React
* Tailwind CSS v4
* JavaScript / TypeScript
* HTML5
* CSS3
* Responsive Design

## ✨ Features

* Modern and premium jewelry store design
* Fully responsive layout
* Persian RTL interface
* Product showcase
* Product details
* Shopping cart
* Cart drawer
* Checkout page
* Detailed order invoice
* Responsive navigation
* Modern and user-friendly interface
* Optimized experience for desktop, tablet, and mobile

## 💍 Jewelry Store

The website provides an elegant shopping experience for browsing gold and jewelry products, viewing product information, and managing items through the shopping cart.

## 🛒 Shopping Cart

Users can add products to their cart, review selected items, manage quantities, and proceed to the checkout page for a detailed order summary.

## 📱 Responsive Design

The website is optimized for:

* 💻 Desktop
* 📱 Mobile
* 📲 Tablet

## 🚀 Getting Started

First, install the project dependencies:

```bash
npm install
```

Then, start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

## 📦 Deployment

The project is deployed on **Vercel**.

[View Live Project](https://zarringold.vercel.app/)
